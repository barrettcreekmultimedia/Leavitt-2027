# Leavitt Machinery — 2027 proposal

Static GitHub Pages site. Upload index.html and .nojekyll to the repository root on main. In Settings > Pages choose Deploy from a branch, main, /(root), and Save. Open the URL displayed by GitHub when deployment finishes.

For local preview, open index.html in a browser. No dependencies, installation, or build step. All sections expand for printing.

Confidentiality: GitHub Pages is generally public even when the source repository is private, depending on plan and configuration. The noindex directive discourages search indexing but does not restrict access. Use authenticated hosting if pricing must remain private.
